# P1-T12 (TS SDK) and P1-T13 (Web UI v1)

## P1-T12: `@ezmd/sdk`

- **Types from OpenAPI.** `packages/sdk-ts/scripts/generate.mjs` runs `openapi-typescript` 7.13.0 (MIT, dev only)
  on `docs/api/openapi.json` (exported by `apps/api/scripts/export_openapi.py`; `apps/api/tests/test_api_meta.py`
  keeps that file fresh) and writes `src/openapi.d.ts`. Two CI checks stop drift:
  `test/openapi-drift.test.ts` (under `pnpm test`) fails when `openapi.d.ts` is stale; `test/contract.ts` (under
  `pnpm typecheck`) fails when a schema (JobOut, InputOut, LinksOut, ConvertResponse, ErrorDetail,
  CapabilitiesOut, ConverterOut, LimitsOut, WarningCodeOut) gains or loses a field the public types do not
  mirror, or when the JobState/Severity/challenge enums diverge. The public types in `src/types.ts` stay
  hand-shaped: they narrow `string` enums to unions and give JSON blobs (error, needs_action) shapes.
  Documented SDK-only fields: `Capabilities.instance_name`/`sponsor` (spec 4.1.2 step 12, not served yet),
  `ConverterOut.extensions` (optional).
- **Surface added:** `events(id)` async iterator (SSE, falling back to polling, ending with a terminal event,
  closing the stream when the consumer breaks), `result(id, {profile, format})`, `warningCodes()`
  (GET /v1/warnings), `deleteJob(id)`, `WarningCodeInfo`; `Job.warnings` (codes), nullable
  `created_at`/`expires_at` to match the API; already-aborted signals reject immediately.
- **Size gate:** the existing `scripts/size-check.mjs` (gzip level 9, 8 KB limit on ESM and CJS) stands in for
  `size-limit`; it is the same check without another dependency tree. Now 3.3 KB / 3.5 KB.
- **Not done:** the ">8 MB multipart upload path" (Part 3 has a single multipart POST; every file goes that
  way). The compose-stack Node integration test belongs to P1-T15/CI.

## P1-T13: Web UI v1

Stack stays per D-0010 (plain CSS tokens, marked + DOMPurify), not the spec's Tailwind/react-markdown list.

- **Warnings:** the UI loads the registry from GET /v1/warnings once (severity, suggestion, aliases) and layers
  it over a bundled copy generated from `packages/core` (`scripts/gen-warning-codes.mjs`, now with aliases), so
  it works offline and before the call returns. Spec 4.1.2 step 8 wording overrides five codes
  (`injection_flagged` is an alias of `injection_suspected`); `pages_without_text` uses the count and
  `duration_cap_exceeded` formats MM:SS when the warning detail carries `limit_seconds`/`max_seconds`.
  Coverage test: every canonical code and alias in codes.py has a non-empty action; the generated JSON must
  equal a fresh parse of codes.py.
- **Downloads:** `.md` (body with frontmatter), `.txt` (server), `.json` (sidecar), `.zip` (server bundle), and
  "Download all as zip" (client side, `fflate` 0.8.3, MIT, ~4 KB gz, lazy chunk) once two or more results are
  done. `.docx` is hidden (API answers 501, no `docx_export` capability); `.srt` waits for transcript segments.
- **History:** `ezmd.history.v1` (50 rows, 200-char preview, never bodies). "Keep result on this device"
  stores the body in IndexedDB (`lib/localstore.ts`, every call resolves, never throws); expired rows show
  "Expired on the server" and open the kept copy with no requests. "Clear history" wipes both stores.
- **Turnstile** renders only when `capabilities.challenge == "turnstile"` and a site key is present.
- **Progress** accepts 0..100 (this API) or a 0..1 fraction.

New dependency: `fflate` 0.8.3, MIT (verified LICENSE), ~30 KB unpacked, 4.4 KB gz in a lazy chunk, for the
client-side zip-all (spec 4.1.3).

## API gaps (reported, not changed here)

- Capabilities has no `instance_name`/`sponsor` (footer line) and no `docx_export` flag.
- No queue position in job state or progress events ("Waiting in queue (position N)").
- Progress events have no `detecting`/`transcribing`/`ocr` stage names yet; the UI maps them when they appear.
