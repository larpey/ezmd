# P1-T17: docs skeleton (README, CONTRIBUTING, SECURITY, CODE_OF_CONDUCT, MkDocs site)

## Approach

- Site generator: MkDocs 1.6 with Material, pinned `mkdocs>=1.6,<2`. Material's own banner warns that
  MkDocs 2.0 removes the plugin system and is unlicensed; the pin keeps the build on 1.x until that settles.
- Root files (CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, CHANGELOG, STATUS, ROADMAP) are rendered into the
  site with `pymdownx.snippets` (already installed with Material) rather than `mkdocs-include-markdown-plugin`,
  so no extra dependency. Consequence: those files must not contain relative Markdown links, because the
  links would resolve against `docs/` and fail `--strict`; they name paths in code spans instead.
- OpenAPI: `mkdocs-swagger-ui-tag` renders `docs/api/openapi.json` on `docs/api-reference.md`. It vendors
  the Swagger UI assets into the site (no CDN), which matches the API's own no-CDN rule.
- `docs/decisions/*.md` are built but kept out of the nav (`not_in_nav`); they are engineering notes.
- Converter matrix: `tools/gen_converters_matrix.py` writes `docs/converters/README.md` from each family's
  `converters()` and rewrites the generated "Converters" block of `mkdocs.yml` from the pages in
  `docs/converters/`. The output must not depend on the machine, so it never shows whether an engine is
  installed (that is `ezmd capabilities`): Install is derived from `requires_extras` checked against the
  extras actually defined in `packages/converters/pyproject.toml` (an undefined extra, today `iwork`, is
  shown as "planned"); Status is Experimental (`experimental = True`), Planned (undefined extra), or Beta
  (everything else until the first release). Families behind a flag (`FLAG_ENV` plus a
  `converters(env=...)` parameter, today `social`) are documented with the flag on. Engine is the id
  suffix, per the `family.engine` id convention. Fixture counts come from `fixtures/*/*/meta.toml`;
  thresholds from `ezmd.testing.fixtures.thresholds`.
- README commands: `tests/test_readme_commands.py` requires a `<!-- readme: run -->` or
  `<!-- readme: skip (reason) -->` marker before every sh/python block. Runnable lines must be
  `uv run ezmd ...` and are invoked in-process through the Typer app from a temporary directory with
  `fixtures/` paths made absolute; the Python block is executed the same way. Skipped blocks (clone,
  install, unpublished packages, Docker, servers, network) are reported as skips with their reason.
- Install is phrased "from source" everywhere; PyPI, npm, `uvx`, and GHCR commands are labelled "after
  the first release".

## Contributor Covenant license

Verified: version 2.1 was published while the Contributor Covenant repository's `LICENSE.md` was the
Creative Commons Attribution 4.0 International license (commit 91532d80ea, January 2022). The repository
switched to the Hippocratic License 3.0 in July 2025 with the v3 redesign, which does not apply
retroactively to the 2.1 text. Reuse with attribution is allowed; `CODE_OF_CONDUCT.md` keeps the original
attribution section and adds the license line. The only adaptation is the enforcement contact.

## Findings for other owners

- The `docs`, `data`, and `7z` extras are defined on `ezmd-converters`, not on `ezmd`, so the
  messages "pip install 'ezmd[docs]'" (pdf `engine_fallback`, `documents.docling_pdf` reason) and
  "pip install 'ezmd[data]'" (`data.parquet` reason) will not work after release unless `ezmd` gains
  passthrough extras (`docs = ["ezmd-converters[docs]"]` and so on). The docs here say
  `uv sync --all-packages --extra <name>` from source.
- `--engine pdf=docling` does not resolve (`resolve_engine` matches dotted segments, and the id is
  `documents.docling_pdf`); the docs use `--converter documents.docling_pdf`.
- The compact profile's frontmatter shows `warnings: []` while the CLI prints info-level warnings for the
  same conversion (for example `tracked_changes_present` on `fixtures/office/docx-review`); that may be
  intended (compact filters info), but it is worth confirming against the spec.

## New dependencies (dev group only)

- `mkdocs>=1.6,<2` (locked 1.6.1), BSD-2-Clause, already present transitively; pinned below 2.0.
- `mkdocs-swagger-ui-tag>=0.7` (locked 0.8.1), MIT (LICENSE read in the installed package; bundles Swagger
  UI, Apache-2.0), about 1.5 MB; renders the OpenAPI reference without a CDN.
  Pulls `beautifulsoup4` 4.15.0 (MIT) and `soupsieve` 2.10 (MIT).
