# P1-T07: SEC EDGAR converter and social stubs

Date: 2026-10-08. Task: P1-T07. Status: proposed (folded into DECISIONS.md at merge).

## D-P1-T07-1: EDGAR implemented directly, not on edgartools

Context: part2 12b names `edgartools` (MIT). Research (PyPI JSON and the repository LICENSE file, 2026-10-08):
edgartools 5.61.1, LICENSE is MIT (verified on GitHub `dgunning/edgartools`, `LICENSE.txt`). Its hard
dependencies include `Unidecode` (1.4.0, GPL-2.0-or-later per its classifiers), `pyarrow`, `pandas`, `rich`,
`httpxthrottlecache`, and `pyrate-limiter`. It also performs its own HTTP through httpx, bypassing
`intomd.core.netguard`, and keeps the identity in global state.

Decision: implement against the documented EDGAR endpoints with the libraries already in the default install
(lxml through the web family's HTML-to-IR module, httpx through netguard):
`www.sec.gov/Archives/edgar/data/<cik>/<acc>/<file>`, `<acc>-index.html` (filing facts and document types),
`data.sec.gov/submissions/CIK##########.json`, `www.sec.gov/files/company_tickers.json`, and
`efts.sec.gov/LATEST/search-index`. A GPL transitive dependency cannot be in the default install, and putting
the converter in the `nonfree` extra for a Unidecode transitive would hide a Phase 1 converter for no gain.

Approach note (part1 2.5):
- Library: none new. Entry point `intomd_converters.edgar.converter.EdgarConverter`.
- Known issues of EDGAR HTML: CSS-styled bold (`font-weight:700` on spans), every table cell wrapped in a
  `<div>` (would make the web family call every table a layout table), `$` and `)` in separate cells, spacer
  columns, tables of contents that repeat every item heading, page numbers and "Table of Contents" links at
  every page break, hidden `ix:header`, Wingdings check boxes.
- Mitigations: pre-pass that reads `dei:` facts, drops `ix:header`, turns CSS bold/italic into tags, unwraps
  cell wrappers, maps Wingdings boxes; post-pass that tidies tables (drop empty rows/columns, fold `$`, `)`,
  `%`), recognizes PART/Item/SIGNATURES headings only when bold or real headings, keeps the last occurrence
  of each item key (the first ones are the TOC), keys 10-Q items by part, removes page furniture, and
  rewrites provenance to `item/<id>` with the accession as `source_id`.
- Network: offline first; `allow_network` gates every request; identity required (hard fail, no retry loop
  on 403/429); 5 requests/second process-wide limiter; deadline checked per request; netguard for SSRF and
  byte caps; injectable transport so tests never touch the network.
- Fallback: none inside the family; an EDGAR HTML body that the converter rejects falls back to the web chain
  (errors are `retryable_with_fallback=True` except identity, rate limit, and lookup failures).
- Fixtures: `edgar/tva-8k` (recorded 8-K by the Tennessee Valley Authority, a corporate agency of the United
  States; a U.S. Government work under 17 U.S.C. 105; recorded unmodified), `edgar/tva-8k-index` (SEC-generated
  index page), `edgar/synthetic-10k` (self-generated by `fixtures/edgar/_generate.py`). Company filings by
  private issuers were deliberately not recorded: they are public records but not public domain.
- Threshold: 0.95 (part2 12g text_similarity); item headings and the statement cells are asserted exactly in
  unit tests.

Not done (documented in docs/converters/edgar.md): XBRL statements and facts tables (12c step 4, with the
XbrlConverter), the PDF classifier, table captions as `Table.caption`.

## D-P1-T07-2: Family placement and ids

EDGAR is `specialized.edgar` in its own subpackage `intomd_converters.edgar` (family `specialized`; the
converter contract test requires the id prefix to match the family). It owns no mime chain: it claims by URL
at 0.95, and the registry's specialist rule (D-0021) puts it ahead of the `text/html` chain.

Social stubs are `web.social_reddit` and `web.social_hn` (family `web`; there is no `social` family in
`FAMILIES`) in subpackage `intomd_converters.social`, behind `INTOMD_ENABLE_SOCIAL` (off by default: registered
as `Unavailable`, so they need no fixture and cannot change routing). On: experimental converters that raise
`FetchRequired` for the sanctioned API URL and render the shared `ThreadNode` model. Full adapters: P3-T02.

## D-P1-T07-4: Fixture provenance (Skeptic review follow-up)

`edgar/tva-8k` is labelled public domain because TVA is a corporate agency of the United States and its
filings are prepared by its officers and employees; 17 U.S.C. 105 excludes works of the U.S. Government from
copyright. This is defensible but not settled law for federal corporations (TVA's employees are not covered
by most civil-service statutes, and no court has ruled on TVA filings specifically). If a reviewer prefers
certainty, replace it with a self-generated 8-K; the converter tests do not depend on its exact text beyond
the item headings. `edgar/tva-8k-index` is an SEC-generated page (the SEC is a federal agency), so it is
public domain without that caveat. `edgar/synthetic-10k` is fictitious and uses a non-SEC placeholder URL
(`filings.example.invalid`); it is converted with the converter forced, which this review also made
possible (a saved filing with no EDGAR URL converts when `--converter specialized.edgar` is given).

Review fixes: Wingdings check boxes inside inline XBRL tags are mapped; the index page keeps each filer's
role, mailing and business addresses, and phone, and marks inline XBRL documents; a plain "TABLE OF
CONTENTS" caption is kept (only linked "Table of Contents" navigation is page furniture); the synthetic
income statement foots.

CLI `--form`/`--year` (core change request 2) was not added: a ticker as the CLI source is resolved as a
file path by `intomd.library._ref`, so the flags would need library support too, which is more than a small
CLI edit. Today: pass the `browse-edgar?CIK=<ticker>&type=<form>` URL.
